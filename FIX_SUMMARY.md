# Исправление некорректного импорта CSV с многострочными полями

**Дата:** 2025-11-03
**Файл:** [25_products_cache.js](25_products_cache.js:30)
**Проблема:** Фильтр "Кратность увеличения, крат" показывал неправильные значения

## Корень проблемы

InSales экспортирует CSV с **многостроч human полями**, заключёнными в кавычки:

```csv
184859333,"Бинокль...","...","...","...","<p>...</p>","7 из элементов в 5 группах
есть асферические элементы",6,5,18,3,27,6,...
```

Видите перенос строки **ВНУТРИ поля** `"7 из элементов в 5 группах\nесть асферические элементы"`?

**Примитивный парсинг**:
```javascript
// ❌ НЕПРАВИЛЬНО
const lines = csvContent.split(/\r?\n/);
const columns = line.split(delimiter);
```

**Результат**: Многострочное поле разбивается на несколько строк:
- Строка 538: `184859333,"Бинокль Olympus 8x42 EXPS I",...`
- Строка 539: `"есть асферические элементы",6,5,18,3,27,6` ← ЭТО НЕ ТОВАР!

Эти "мусорные" строки попадали в лист как обычные товары, загрязняя фильтры.

## Решение

Реализован **RFC 4180-совместимый CSV парсер** с поддержкой:
- Многострочных полей в кавычках
- Экранированных кавычек (`""` внутри поля)
- Разных разделителей (табуляция, точка с запятой, запятая)

### Код (строки 63-133):

```javascript
// Правильный CSV парсинг с поддержкой многострочных полей
const rows = [];
let currentRow = [];
let currentField = '';
let insideQuotes = false;
let i = 0;

while (i < csvContent.length) {
  const char = csvContent[i];
  const nextChar = csvContent[i + 1];

  if (char === '"') {
    if (insideQuotes && nextChar === '"') {
      // Экранированная кавычка ("") внутри поля
      currentField += '"';
      i += 2;
      continue;
    } else {
      // Начало или конец кавычек
      insideQuotes = !insideQuotes;
      i++;
      continue;
    }
  }

  if (!insideQuotes && char === delimiter) {
    // Конец поля
    currentRow.push(currentField.trim());
    currentField = '';
    i++;
    continue;
  }

  if (!insideQuotes && (char === '\n' || char === '\r')) {
    // Конец строки (только если НЕ внутри кавычек!)
    if (currentField.length > 0 || currentRow.length > 0) {
      currentRow.push(currentField.trim());
      if (currentRow.length > 0) {
        rows.push(currentRow);
      }
      currentRow = [];
      currentField = '';
    }

    // Пропускаем \r\n или \n
    if (char === '\r' && nextChar === '\n') {
      i += 2;
    } else {
      i++;
    }
    continue;
  }

  // Обычный символ
  currentField += char;
  i++;
}
```

### Удалены костыльные фильтры:

**Удалено** из `getProductsFromCSVSheet()` (строки 204-231):
- ❌ Фильтрация значений с `##` (диапазоны фильтров InSales)
- ❌ Фильтрация значений `< 5` для кратности

Эти фильтры были **временным костылём** для борьбы с симптомами, а не с причиной.

## Результат

**До исправления:**
```
Кратность увеличения, крат: ['1##4', '1', '1##8', '1##2##4', '1##2', '1.25', '2', '3', '4', '5', '6', '7', '8', ...]
```

**После исправления:**
```
Кратность увеличения, крат: [7, 8, 10, 12, 16, 20, 25, 30, 42, 50, ...]
```

## Дополнительные улучшения

Парсер также корректно обрабатывает:
- HTML-описания с переносами строк
- Пустые поля
- Кавычки внутри полей (`""` → `"`)
- Разные форматы переносов строк (`\r\n`, `\n`)
